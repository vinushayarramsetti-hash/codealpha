# CodeAlpha Data Analytics Internship

## Overview

This repository contains the projects completed as part of the **CodeAlpha Data Analytics Internship**.

The repository includes three Data Analytics tasks:

* **Task 2 — Exploratory Data Analysis (EDA)**
* **Task 3 — Data Visualization**
* **Task 4 — Sentiment Analysis**

These projects demonstrate practical applications of data analysis, data visualization, and sentiment classification using Python.

---

## Task 2 — Exploratory Data Analysis (EDA)

### Objective

The objective of this task is to explore a sales dataset, understand its structure, check data quality, identify patterns and trends, and perform basic statistical analysis.

### Activities

* Load and inspect the dataset
* Understand data types and structure
* Check missing values
* Check duplicate records
* Perform descriptive statistical analysis
* Analyze sales by category
* Analyze sales by region
* Analyze monthly sales
* Create data visualizations

### Output Files

```text
Task2_EDA/
├── sales_data.csv
├── 01_sales_by_category.png
├── 02_monthly_sales_trend.png
├── 03_sales_distribution.png
├── 04_category_boxplot.png
└── 05_correlation_matrix.png
```

---

## Task 3 — Data Visualization

### Objective

The objective of this task is to transform sales data into meaningful visualizations and create a dashboard for easier interpretation of business performance.

### Visualizations

* Total Sales KPI
* Total Profit KPI
* Total Quantity KPI
* Monthly Sales Trend
* Sales by Category
* Sales by Region
* Payment Method Distribution
* Sales Analytics Dashboard

### Output Files

```text
Task3_Data_Visualization/
├── sales_data.csv
├── Sales_Analytics_Dashboard.png
├── 01_sales_by_region.png
└── 02_payment_method_pie.png
```

---

## Task 4 — Sentiment Analysis

### Objective

The objective of this task is to analyze customer reviews and classify the text into three sentiment categories:

* Positive
* Neutral
* Negative

### Activities

* Load review data
* Process review text
* Identify positive and negative words
* Classify reviews based on sentiment
* Count sentiment categories
* Create a sentiment distribution visualization

### Output Files

```text
Task4_Sentiment_Analysis/
├── reviews.csv
└── Sentiment_Distribution.png
```
